## 🔧 Quick Troubleshooting

Before contacting support, try these simple solutions.

### 1. Restart Dragon

Close Dragon completely and start the application again.

### 2. Check your connection

Make sure your internet connection is working correctly.

### 3. Check for updates

Make sure you're using the latest available version of your Dragon product.

### 4. Restart your device

Restarting your computer or device can resolve temporary issues.

### 5. Check the error message

If Dragon displays an error, save the exact error message so support can help you faster.

## ❓ Frequently Asked Questions

### How do I get started with Dragon?

Install your Dragon product and follow the setup instructions. Complete the activation process if required.

### Why isn't Dragon working?

Restart Dragon first and check for available updates. If the problem continues, contact Dragon Support.

### I can't access my account. What should I do?

Check your login information and try the password recovery option if necessary.

### How can I get technical help?

Review the troubleshooting information above. If you still need assistance, contact Dragon Customer Support.
